# Парсер публикаций школьного сообщества ВК

Скрипт загружает публикации за выбранный месяц и делает два редактируемых файла Word: `useful.docx` (школьные новости) и `review.docx` (реклама, постороннее и всё, в чём классификатор не уверен). Ничего не удаляется: исходные посты также сохраняются в `posts.json`. По умолчанию задан паблик `https://vk.ru/schoolkng1` и октябрь 2026 года.

## Запуск

Нужен Python 3.10 или новее. В терминале из каталога репозитория:

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r schoolpostparser/requirements.txt
```

Получите токен VK API, которому разрешено чтение открытых стен, и передайте его через переменную окружения (не вставляйте токен в файл и не отправляйте его в Git):

```bash
# macOS/Linux
export VK_TOKEN='ваш_токен'
python schoolpostparser/parse_posts.py --month 2026-10
```

```powershell
# Windows PowerShell
$env:VK_TOKEN='ваш_токен'
python schoolpostparser/parse_posts.py --month 2026-10
```

Результаты появятся в `output/`. Можно выбрать другой месяц и папку:

```bash
python schoolpostparser/parse_posts.py --url https://vk.ru/schoolkng1 --month 2026-09 --out output-september
```

Если доступ к API не получается, передайте JSON-экспорт стены (массив постов либо ответ VK API с `response.items`):

```bash
python schoolpostparser/parse_posts.py --json wall.json --month 2026-10
```

## Как устроено и как настроить

1. `utils.resolveScreenName` преобразует короткое имя сообщества в числовой ID, затем `wall.get` читает стену порциями и выбирает посты нужного месяца.
2. Текст очищается от ссылок на публикацию/комментарии и VK-упоминаний. Фотографии берутся из вложений поста (до двух самых крупных на публикацию).
3. Простые русскоязычные ключевые слова в `USEFUL` помечают школьные новости как полезные. Рекламные маркеры `AD` всегда отправляют пост на проверку. Всё неоднозначное также попадает в `review.docx`, чтобы не терять потенциально важные материалы.
4. Откройте оба DOCX, проверьте разделение и текст, при необходимости перенесите пост между файлами. Скрипт не переписывает текст средствами ИИ: он убирает типичный сетевой мусор и форматирует исходную публикацию, так что фактические формулировки и имена остаются проверяемыми.
5. Для изменения критериев отредактируйте регулярные выражения `USEFUL` и `AD` в начале `parse_posts.py`. Для изменения размера фото — параметры `width=Cm(...)` в `make_doc`.

## Ограничения

- VK может потребовать действующий токен/API-доступ; публичная страница сама по себе не гарантирует программный доступ к архиву.
- Автоматическая тематическая сортировка — только предварительная, поэтому предназначена для проверки человеком, а не для безусловного решения.
- Макет отводит каждой публикации отдельную страницу, использует поля A4, Arial 10,5 пт и максимум две фотографии. Очень длинный пост может автоматически перейти на следующую страницу Word; его нужно проверить и сократить/уменьшить фото вручную.
- Время фильтрации задано по UTC. Для постов около полуночи на границе месяца стоит отдельно перепроверить дату.
- Токен и персональные данные не коммитьте. Каталог `output/` добавлен в `.gitignore`.
